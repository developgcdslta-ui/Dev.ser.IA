# Jogos da comunidade

Cada jogo fica numa pasta própria, com o nome em minúsculas e hífens (o `slug`):

```
jogos/corrida-lunar/
├── cartucho.html
├── capa.png        (ou capa.webp; quadrada, 1024 a 1254 px, até 3 MB)
└── ficha.json
```

A pasta [`_exemplo/`](_exemplo/) mostra a `ficha.json`. Pastas que começam com `_` não são jogos e o validador as ignora.

Regras, checklist e termo de envio: [`../docs/06-envio-e-regras.md`](../docs/06-envio-e-regras.md) e [`../CONTRIBUTING.md`](../CONTRIBUTING.md).
